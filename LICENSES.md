# Licensing plan

This repository is a mixed hardware/software project. It will not use one root license to relicense third-party materials.

Planned licensing for **original project contributions only**:

- Software source: Apache-2.0.
- Original hardware design files (CAD, PCB, schematics): CERN Open Hardware Licence Version 2 - Strongly Reciprocal (CERN-OHL-S-2.0), subject to adding the complete license text and required source-location notices before the first hardware release.
- Original documentation: Creative Commons Attribution 4.0 International (CC BY 4.0).

Until the relevant full license files and per-directory notices are added, treat this as a licensing plan, not a completed license grant.

Third-party components retain their own licenses. See third_party/UPSTREAMS.md. In particular, do not copy upstream CAD, source code, models or policies into this repository without retaining their original notices and satisfying the exact license terms.
