# Contributing

Thank you for helping with GPT-Mecha 40.

## Current priorities

- Verify upstream Open Duck Mini V2 mechanical and electrical details.
- Review CAD clearances and armor keep-out zones.
- Check actuator voltage variants and power design.
- Improve simulation and sim-to-real documentation.
- Build safe voice, vision and high-level AI interfaces.

## Contribution rules

1. Open an issue before major mechanical or electrical changes.
2. Keep upstream reference files separate from original project work.
3. Include source and license information for imported assets.
4. Record measured dimensions; label estimates clearly.
5. Do not claim a design is tested unless the test was actually performed.
6. Include safety implications for changes to actuators, batteries, power and autonomy.
7. Never commit API keys, Wi-Fi credentials, personal data or private customer information.

## CAD contributions

Include editable source files, neutral STEP exports, print STL files, dimensions, material, print orientation and a mass estimate. Identify which upstream interfaces are preserved or changed.

## Hardware and software tests

Document hardware revision, firmware/software commit, actuator model and voltage, supply voltage, test fixture, measured current/temperature, observed faults and test result. Walking tests must use a support gantry until explicitly validated.

## Licensing

Do not submit assets unless you own them or have verified a license compatible with the intended distribution. Preserve required notices and attribution.
